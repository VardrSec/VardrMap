# v0.19.2 — Automated Dependency Updates

**Date:** 2026-06-13

Tooling change. Adds Dependabot so dependency and GitHub Actions updates arrive
as routine, reviewable PRs instead of surfacing when CI's audit gate fails.

## Added

- `.github/dependabot.yml` — weekly update checks across four ecosystems:
  - `npm` in `frontend/`
  - `pip` in `backend/` and `runner/`
  - `github-actions` workflow pins (keeps `checkout` / `setup-node` /
    `setup-python` / `gitleaks` current)
- Routine minor/patch bumps are grouped into one PR per ecosystem per week;
  major bumps and security updates open individually for review.

## Why

v0.19.1 fixed a CI-blocking `npm audit` failure by hand. Dependabot turns that
reactive scramble into a steady stream of small PRs, and keeps the Actions pins
current so the next runtime deprecation (like the Node 20 → 24 flip) is flagged
early rather than discovered in a red build.

No application, endpoint, model, or env var changes.
