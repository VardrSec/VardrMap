# v0.20.3 — 2026-06-23

## Connect Runner setup panel

Eliminates the "remember the commands, find your token, check the URL" dance when
setting up VardrRunner on a new machine.

### Settings — Connect Runner panel

- **Generate Runner Key** button creates a runner-scoped API key labeled
  "VardrRunner (connect)" and immediately shows the three setup commands
  prefilled with your actual backend URL and the fresh token:
  1. `vardrrunner login vardrmap --url <url> --token <token>`
  2. `vardrrunner daemon start`
  3. `vardrrunner doctor`
- Per-command **Copy** button — one click, correct command in clipboard.
- **Download .ps1** — downloads `vardrrunner-connect.ps1` with all three
  commands; double-click once on Windows to bootstrap the runner.
- **Verify connection** button polls `GET /runner/status` and shows
  "online ✓" / "offline ✗" inline so you know immediately whether the
  runner reached the backend.
- **Regenerate key** link revokes the previous runner key and issues a fresh
  one (all commands update in place).
- The generated key is runner-scoped (jobs, imports, heartbeat only); it
  appears in Active Keys and can be revoked there when rotating.

### Bridge — offline state

- Replaced the static `$ vardrrunner jobs run` hint with a **"set up runner →"**
  button that navigates directly to Settings → Connect Runner.
