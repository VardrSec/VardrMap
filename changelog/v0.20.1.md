# v0.20.1 — Dashboard stats, search/filter, finding→submission promotion

**Date:** 2026-06-20

## Added

- **Dashboard stats row** — four clickable metric cards (Recon assets, Findings,
  Accepted, Paid) load in parallel on mount and navigate to the relevant section
  on click. A severity breakdown row shows finding counts by severity as colored
  pills that also navigate to Findings.

- **Findings search + severity filter** — a search box (matches title or asset,
  server-side `ILIKE`) and a severity select now sit above the Finding Tracker
  panel. Filters are applied immediately on severity change and on search form
  submit. A "Clear" button appears when either is active.
  Backend: `GET /programs/{id}/findings` now accepts `?search=` and `?severity=`.

- **Submissions status + platform filter** — a status select and a platform text
  input above the submissions table send `?status=` / `?platform=` to the API,
  which applies them at the DB query level. "Clear" button resets both.
  Backend: `GET /programs/{id}/submissions` now accepts `?status=` and `?platform=`.

- **Finding → Submission promotion** — each finding card now has a
  "Log Submission →" button (green hover) alongside "Draft Report →". Clicking
  it pre-fills the Submissions form with the finding title and `finding_id`, then
  navigates to the Submissions section.
