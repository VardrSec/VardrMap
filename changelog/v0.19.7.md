# v0.19.7 — TypeScript 6 upgrade

**Date:** 2026-06-20

Bumps the frontend from TypeScript 5.9.3 to 6.0.3 and fixes the three CI failures
that blocked Dependabot PR #16.

## Changed

- **`frontend/package.json`** — `typescript` bumped to `^6.0.3`.

- **`frontend/tsconfig.test.json`** — Two fixes required for TS6:
  - Added `"rootDir": "."` — TS6 now requires explicit `rootDir` when the inferred
    common source directory of test files (e.g. `app/components/__tests__`) differs
    from the project root (TS5011).
  - Added `"ignoreDeprecations": "6.0"` — the test config inherits `baseUrl` and
    `moduleResolution: node` from the main tsconfig; both are deprecated in TS6 but
    required by Jest's CommonJS environment. `ignoreDeprecations` is the official
    migration path (TS5101, TS5107); these options continue to work until TS7.

- **`frontend/jest.config.js`** — Migrated ts-jest configuration from the deprecated
  `globals["ts-jest"]` form to the `transform` array form:
  ```js
  transform: { "^.+\\.tsx?$": ["ts-jest", { tsconfig: "tsconfig.test.json" }] }
  ```

## Verified

- 55 Jest tests pass under TypeScript 6.
- `npm run lint` and `npm run build` clean.
