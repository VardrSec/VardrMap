# v0.19.8 — Frontend section tests

**Date:** 2026-06-20

Adds workflow tests for the three previously-untested core sections, bringing the
frontend suite from 55 to 70 tests.

## Added

- **`FindingsSection.test.tsx`** (5 tests)
  - Empty state, renders loaded findings, add via POST, delete via DELETE, promote-to-report,
    AI suggest (POST /suggest) applies impact/remediation and shows CVSS message.

- **`SubmissionsSection.test.tsx`** (5 tests)
  - Stats row after empty load, renders loaded submissions, create via POST, delete via DELETE,
    `submissionPrefill` context opens form with title pre-filled and dispatches
    `SUBMISSION_PREFILL_CONSUMED`.

- **`JobsSection.test.tsx`** (4 tests)
  - Verifies all four mount-time fetches (`/jobs`, `/runner/status`, `/recon?limit=1`,
    `/schedules`), renders Composer panel, queues a one-time job via POST `/jobs`,
    creates a schedule via POST `/schedules` after picking a recurrence.
  - Bridge is stubbed out (it calls `Object.entries` on `runnerStatus.tools` before
    the first fetch resolves, crashing the test render).

## Notes

- `Input` component in `ui.tsx` has no `htmlFor`/`id` pairing — tests use
  `getAllByRole("textbox")[0]` to target the Title field. The same applies to
  `getPlaceholderText` where inline placeholders are available.
