# v0.20.0 — Recon host detail panel

**Date:** 2026-06-20

Clicking any row in the Recon discovered-assets table now opens a slide-over
panel that aggregates all tool data for that host in one view.

## Added

- **`HostDetailPanel.tsx`** — fixed side-panel (480 px) showing:
  - **Recon details** — status code, page title, web server, tech stack,
    content-type, and source tool for the selected recon entry.
  - **Services** — nmap-discovered ports filtered to this host (port/protocol,
    service name, product/version, open/closed state).
  - **Vulnerabilities** — nuclei scan items whose `asset` matches this host,
    by severity and template ID.
  - **Findings** — saved findings whose `asset` matches this host, with severity
    and status. "Open Findings →" navigates to the Findings section.
  - Host-matching is bidirectional subdomain-aware:
    `h === host || h.endsWith('.${host}') || host.endsWith('.${h}')`.

- **`ReconSection.tsx`** — recon rows are now `cursor-pointer` with hover
  highlight. Clicking a row sets `detailItem`, mounting the panel.
  A `key={item.id}` on the panel ensures a fresh mount (and fresh loading
  state) when switching between hosts without closing.

## Notes

No backend changes. Services, scans, and findings are fetched in parallel on
panel open and filtered client-side. For programs with thousands of findings or
scans, the `limit=500` cap means results beyond that page won't appear — this
is acceptable for the v1 panel.
