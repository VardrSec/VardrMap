# v0.16.0 — 2026-06-11

## Submission Tracker
- New `submissions` table + Alembic migration 0009
- `GET /programs/{id}/submissions`, `POST`, `PATCH`, `DELETE` endpoints with full BOLA scoping
- Status lifecycle: `submitted → triaged → accepted | duplicate | na | paid | rejected`
- Auto-stamps `resolved_at` when status transitions to a terminal state
- `SubmissionsSection` — new sidebar section with stats row (total, acceptance rate, total payout), submission table, inline edit form, and new submission form
- `Submission` type added to `frontend/app/types.ts`
- `Section` type extended with `"submissions"`

## Delete Stuck Job
- `DELETE /jobs/{job_id}` — permanently removes a job and all its events (CASCADE); accepts any job status so stuck `running` jobs (from a crashed runner) can be force-deleted
- Terminal footer now shows a **delete** button for all job states; `title` distinguishes force-delete (running) from normal delete (done/failed/pending)
- `deleteJob(id)` in `JobsSection` calls the endpoint and removes the job from local state; clears `activeId` if the deleted job was selected

## CI Hardening
- **Secret scanning**: `gitleaks/gitleaks-action@v2` runs on every push and PR against full git history
- **Backend dependency audit**: `pip-audit -r requirements.txt` added to backend CI job after tests pass
- **Frontend dependency audit**: `npm audit --audit-level=high` added to frontend CI job after build
- **Migration consistency check**: `alembic heads` count check in backend CI job — fails if multiple migration heads exist (would cause deploy divergence)
