# v0.19.3 — Webhook SSRF Hardening

**Date:** 2026-06-13

Security hardening for the outbound notification webhooks added in v0.18.0.

## Fixed

### Webhook SSRF — the host is now resolved and checked at send time

The webhook guard previously validated only the URL *string* when a webhook was
saved: it required HTTPS and rejected private/loopback/link-local **IP literals**,
but a hostname that *resolved* to a private or cloud-metadata address (e.g. a
name pointing at `169.254.169.254`) passed validation and was then POSTed to by
the backend. Because the backend itself makes the request, that turned a
user-supplied webhook into a potential SSRF vector against the hosting network —
and v0.19 RBAC means more than one principal can now configure one.

`send_webhook` now resolves the host immediately before sending and refuses the
request if the host does not resolve, or if **any** resolved address is
private/loopback/link-local/reserved/multicast/unspecified:

- The authoritative check runs at **send time**, so it also blocks DNS rebinding
  — a name that passed config-time validation but now points inward.
- A name that resolves to both a public and a private address is refused.
- Config-time `validate_webhook_url` keeps its fast HTTPS + IP-literal pre-check
  (for immediate UX feedback) and now shares the same block-list helper.
- Redirects stay disabled (`follow_redirects=False`).

**Residual risk (documented, accepted for a personal-use tool):** IPv4-mapped
IPv6 forms and the small TOCTOU window between resolution and the HTTP client's
own connect are not fully closed. Pinning the connection to the validated IP
would be the next step if this grows into a multi-tenant service.

## Tests

- Backend: 336 tests (was 329). New `TestSendWebhookSSRF` covers: public host is
  sent; host resolving to a private or metadata IP is blocked; unresolvable host
  is blocked; mixed public+private resolution is blocked; private IP literal is
  blocked without a DNS lookup; `http` scheme is blocked before send.

No endpoint, model, or env var changes.
