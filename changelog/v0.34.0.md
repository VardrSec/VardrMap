# v0.34.0 — Burp-assisted API Surface

VardrMap can now act as the persistent reasoning and visualization layer beside Burp Suite during API penetration tests.

- Added canonical API operations with inferred identifier placeholders, observation counts, response statuses, and logical identity labels.
- Added deliberately promoted HTTP exchanges. Automatic traffic capture is off; query values are discarded and request/response content is redacted before storage.
- Added the Review → API Surface view for filtering operations and comparing retained exchanges.
- Added a Java 21 Montoya extension in `integrations/vardr-burp`. Its context-menu action redacts locally and sends selected messages directly to VardrMap.
- Added authenticated, engagement-scoped API endpoints and BOLA/redaction/upsert tests.
