# v0.19.1 — Frontend Dependency Security + Node 24 CI Readiness

**Date:** 2026-06-12

Maintenance release. No endpoint, model, env var, or user-visible behavior
changes — it clears a CI-blocking dependency audit and prepares CI for the
GitHub-hosted runner Node default flip.

## Security

### Frontend dependency vulnerabilities (CI blocker)

`npm audit --audit-level=high` was failing the **Frontend lint + build** job
with 3 high and 2 moderate advisories. All five are resolved; `npm audit` now
reports **0 vulnerabilities**.

- **`next` 16.1.6 → 16.2.9** — patches a batch of App Router / middleware /
  image-optimization advisories: HTTP request smuggling in rewrites, SSRF via
  WebSocket upgrades, middleware/proxy bypasses, cache poisoning of RSC
  responses, CSP-nonce XSS, and several DoS vectors. Stays within the Next 16
  line (minor bump), so no migration is required.
- **`eslint-config-next` 16.1.6 → 16.2.9** — kept in lockstep with `next`.
- **`flatted`, `picomatch`, `brace-expansion`** — bumped to patched releases via
  `npm audit fix` (all transitive: prototype pollution / ReDoS / DoS).
- **`postcss` override pinned to `^8.5.10`** — `next@16.2.9` still nests
  `postcss@8.4.31`, which carries the CSS-stringify XSS advisory
  (GHSA-qx2v-qp2m-jg93). An `overrides` entry lifts the nested copy to the
  patched 8.5.x line (deduped with the copy Tailwind already uses). npm's only
  automatic remediation was a `next@9.3.3` downgrade, which is rejected.

The `next` pin stays exact (matching the `react` / `react-dom` house style);
security bumps within the 16.x line are deliberate, reviewed edits.

## CI

### Node 24 readiness

GitHub flips the hosted-runner default Node to 24 on **2026-06-16**. The
**Frontend lint + build** job now runs a `[20, 24]` matrix (`fail-fast: false`):

- **20** matches the production runtime (`.nvmrc` / Vercel).
- **24** is the incoming runner default.

Lint, build, and audit run on both legs, so a Node-version regression is caught
before it reaches production. Verified locally on Node 24.14.0.

## Validation

- `npm audit` — 0 vulnerabilities; `npm ci` reproduces cleanly from the lockfile.
- Frontend `npm run lint` + `npm run build` pass on Node 24.
- Backend 329 tests, runner 113 tests, frontend 32 reducer tests — all pass.
