# v0.38.0 — Content Discovery pipeline

**Date:** 2026-10-08

Adds a named composer pipeline that uses the katana and gau job types from v0.37.0.

## Content Discovery

A new chain in the job composer: **subfinder → httpx → katana → gau**. subfinder enumerates
subdomains from the wildcard scope, httpx keeps the ones that answer, katana crawls those
live hosts for endpoints, and gau adds URLs that public archives already hold for the scope
domains. All four feed the recon store, and — like the other pipelines — each stage can be
included or excluded individually. The equivalent on the runner is `vardrrunner pipeline run
content` (VardrRunner v0.39.0).

No backend change: the pipelines endpoint already accepts any ordered chain of existing job
types. This is the UI presenting one more preset.

## Tests

Frontend: `toolCatalog.test.ts` pins the Content Discovery stages and sources and checks that
every pipeline references a tool present in the composer catalog.
